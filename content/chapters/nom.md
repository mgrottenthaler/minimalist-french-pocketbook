## Le genre

Deux genres, marqués par l'article, pas par la terminaison. Le seul test sûr est **le / la**, **un / une** — la forme du nom seule ne garantit rien.

### Repères de terminaison (des tendances, pas des règles)

| Souvent masculin | Souvent féminin |
|---|---|
| -age, -ège, -isme, -ment, -eau, -phone | -ade, -ance/-ence, -ée, -sion/-tion, -té, -ure |
| le fromage, le collège, le tourisme | la promenade, la puissance, la fusée, la nation |

> Nombreuses exceptions : **un** problème, **un** système, **un** silence, **un** squelette, **un** incendie, **un** intervalle (masculins en *-e*) ; **une** main, **une** dent, **une** fin, **une** faim, **une** nuit, **une** forêt, **une** part, **une** fois (féminins sans *-e*).

## Le féminin des noms animés

| Masculin | Féminin | Exemple |
|---|---|---|
| consonne | + **e** | étudiant → étudiant**e** |
| -e | invariable | élève → élève, artiste → artiste |
| -en, -on | **-enne**, **-onne** | gardien → gardi**enne**, lion → li**onne** |
| -er | **-ère** | boulanger → boulang**ère** |
| -eur (verbe en -er) | **-euse** | danseur → dans**euse** |
| -teur (pas de verbe en -ter) | **-trice** | acteur → ac**trice** |
| -f | **-ve** | veuf → veu**ve** |
| -x | **-se** | époux → épou**se** |

> Irrégulier : copain → copine, roi → reine, dieu → déesse, héros → héroïne, neveu → nièce, fils → fille, homme → femme, frère → sœur, oncle → tante, cheval → jument, coq → poule.

## Le pluriel

| Singulier | Pluriel | Exemple |
|---|---|---|
| la plupart | + **s** | livre → livre**s** |
| -s, -x, -z | invariable | un pays → des pays, une voix → des voix |
| -eau, -au, -eu | + **x** | bateau → bateau**x**, tuyau → tuyau**x**, feu → feu**x** |
| -al | → **-aux** | animal → anim**aux**, journal → journ**aux** |
| -ail | + **s** (le plus souvent) | détail → détail**s**, éventail → éventail**s** |

> Exceptions **-al → -als** : bal, carnaval, chacal, festival, récital, régal.
> Exceptions **-ail → -aux** : travail → trav**aux**, corail → cor**aux**, émail → ém**aux**, vitrail → vitr**aux**, bail → b**aux**, soupirail → soupir**aux**.
> Pluriels irréguliers : œil → **yeux**, ciel → **cieux** (ou *ciels*, pour un sens concret : *les cieux de Provence*), aïeul → **aïeux** ("ancêtres"), ou *aïeuls* ("grands-parents").

Les noms de famille sont invariables : *les Dupont*, pas *les Duponts*.

## Noms à double genre

Le genre change le sens.

| | Masculin | Féminin |
|---|---|---|
| livre | le livre — à lire | la livre — poids, monnaie |
| tour | le tour — parcours, tour de magie | la tour — bâtiment |
| poste | le poste — emploi, appareil | la poste — service postal |
| mode | le mode — manière, grammaire | la mode — vêtements |
| voile | le voile — tissu, linceul | la voile — bateau |
| manche | le manche — d'un outil | la manche — de vêtement |
| critique | le critique — personne | la critique — jugement |
