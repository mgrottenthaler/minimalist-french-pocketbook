## Le passé composé

**avoir** ou **être** au présent + **participe passé**.

### Le participe passé régulier

| Groupe | Terminaison | Exemple |
|---|---|---|
| 1er (-er) | **-é** | parler → parl**é** |
| 2e (-ir) | **-i** | finir → fin**i** |
| 3e (-re, le plus souvent) | **-u** | vendre → vend**u** |

Le 3e groupe a aussi des participes en **-is** (*pris, mis*), **-it** (*dit, écrit*) et des formes propres à chaque verbe (*été, eu, fait, né, mort*) — voir le chapitre *Verbes irréguliers*.

### Le choix de l'auxiliaire

La plupart des verbes se conjuguent avec **avoir**. Une liste fermée de verbes intransitifs de mouvement ou de changement d'état, plus **tous les verbes pronominaux**, se conjuguent avec **être**.

| Verbes avec être (non pronominaux) | |
|---|---|
| aller / venir | naître / mourir |
| arriver / partir | monter / descendre |
| entrer / sortir | rester / tomber |
| retourner / rentrer | devenir / revenir |

*Je **suis** allé. · Elle **est** partie. · Nous **sommes** rentrés.*

*Je **me suis** levé. Elle **s'est** habillée.* — tout verbe pronominal, sans exception.

### L'accord du participe passé

| Auxiliaire | Règle | Exemple |
|---|---|---|
| **être** (non pronominal) | s'accorde avec le **sujet** | Elle **est** part**ie**. Ils **sont** venu**s**. |
| **avoir** | s'accorde avec le COD **seulement s'il précède** le verbe | J'ai mangé la pomme. → La pomme que j'ai mang**ée**. |
| **être** (pronominal) | s'accorde avec le sujet, **sauf** si le verbe a son propre COD après | Elle s'est lav**ée**. — mais : Elle s'est lavé **les mains**. (pas d'accord : *les mains* est le COD, il suit le verbe) |

## L'imparfait

Radical de **nous** au présent (sans *-ons*) + terminaisons **-ais, -ais, -ait, -ions, -iez, -aient**, identiques pour tous les verbes.

| | parler | finir | vendre |
|---|---|---|---|
| je | parl**ais** | finiss**ais** | vend**ais** |
| tu | parl**ais** | finiss**ais** | vend**ais** |
| il / elle | parl**ait** | finiss**ait** | vend**ait** |
| nous | parl**ions** | finiss**ions** | vend**ions** |
| vous | parl**iez** | finiss**iez** | vend**iez** |
| ils / elles | parl**aient** | finiss**aient** | vend**aient** |

> Seule vraie exception : **être**, dont le radical est **ét-** (*j'étais, tu étais...*) — tous les autres verbes, même très irréguliers au présent, suivent la règle du radical de *nous*.

## Passé composé ou imparfait ?

| Passé composé | Imparfait |
|---|---|
| action ponctuelle, achevée | description, état, arrière-plan |
| fait rapporté comme un événement | action habituelle ou répétée |
| *Hier, il **a plu** toute la journée.* | *Quand j'étais enfant, il **pleuvait** souvent.* |
| *Je **suis entré**, j'**ai vu** Paul.* | *Il **faisait** beau, Paul **lisait**.* |

Les deux se combinent dans un même récit : l'imparfait plante le décor, le passé composé fait avancer l'action.

*Il **faisait** nuit quand je **suis rentré**.*

## Le plus-que-parfait

**avoir** ou **être** à l'**imparfait** + participe passé — pour une action antérieure à une autre action passée.

| | |
|---|---|
| j' | **avais** parlé |
| tu | **avais** fini |
| il / elle | **avait** vendu |
| je | **étais** parti(e) |

*Quand je suis arrivé, il **était** déjà **parti**.* — le départ précède l'arrivée, elle-même déjà au passé.
