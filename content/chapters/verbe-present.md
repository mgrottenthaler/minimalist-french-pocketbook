## Les trois groupes

Classés d'après la terminaison de l'infinitif et le comportement au présent.

| Groupe | Terminaison | Trait | Modèle |
|---|---|---|---|
| 1er | **-er** (sauf *aller*) | régulier | parler, aimer, manger |
| 2e | **-ir** | infixe **-iss-** au pluriel | finir, choisir, réussir |
| 3e | **-ir, -re, -oir**, et *aller* | irrégulier, plusieurs modèles | partir, vendre, pouvoir, aller |

Le 1er groupe couvre l'immense majorité des verbes français et tout verbe nouveau (*télécharger, cliquer*) ; le 3e groupe est fermé, mais concentre les verbes les plus fréquents de la langue.

## 1er groupe : verbes en -er

| | parler | manger |
|---|---|---|
| je | parl**e** | mang**e** |
| tu | parl**es** | mang**es** |
| il / elle / on | parl**e** | mang**e** |
| nous | parl**ons** | mang**eons** |
| vous | parl**ez** | mang**ez** |
| ils / elles | parl**ent** | mang**ent** |

Les trois personnes du singulier + la 3 pl. **se prononcent toutes pareil** (*parle, parles, parle, parlent* : un seul son) ; seuls **nous** et **vous** se distinguent à l'oral.

### Variations orthographiques

| Terminaison | Changement | Exemple |
|---|---|---|
| **-cer** | c → **ç** devant a/o | commencer → nous commen**ç**ons |
| **-ger** | g → **ge** devant a/o | manger → nous man**ge**ons |
| **e_er** (lever) | e → **è** aux formes accentuées | lever → je l**è**ve, nous levons |
| **é_er** (préférer) | é → **è** aux formes accentuées | préférer → je préf**è**re, nous préférons |
| **-eler, -eter** | consonne doublée, ou **è** | appeler → j'appe**ll**e ; acheter → j'ach**è**te |

## 2e groupe : verbes en -ir (type *finir*)

| | finir |
|---|---|
| je | fin**is** |
| tu | fin**is** |
| il / elle / on | fin**it** |
| nous | fin**issons** |
| vous | fin**issez** |
| ils / elles | fin**issent** |

L'infixe **-iss-**, présent à toutes les personnes du pluriel, est ce qui distingue ce groupe des verbes en *-ir* du 3e groupe (*partir* → *nous partons*, sans *-iss-*).

## 3e groupe : quelques modèles fréquents

| | partir | venir | vendre |
|---|---|---|---|
| je | par**s** | vien**s** | vend**s** |
| tu | par**s** | vien**s** | vend**s** |
| il / elle / on | par**t** | vien**t** | vend |
| nous | part**ons** | ven**ons** | vend**ons** |
| vous | part**ez** | ven**ez** | vend**ez** |
| ils / elles | part**ent** | vienn**ent** | vend**ent** |

*partir* perd sa consonne finale de radical au singulier (*part-* → *pars*) ; *venir/tenir* alternent *ven-/vien-* ; les verbes en **-re** comme *vendre* ne prennent pas de **-t** à la 3 sg. (le radical se termine déjà par *-d*). Le 3e groupe compte des dizaines de modèles distincts — la table du chapitre *Verbes irréguliers* couvre les plus utiles.

## Les auxiliaires : être, avoir, aller

Trois verbes dont dépend tout le reste du système — temps composés, futur proche, passé récent. À apprendre intégralement.

| | être | avoir | aller |
|---|---|---|---|
| je | **suis** | **ai** | **vais** |
| tu | **es** | **as** | **vas** |
| il / elle / on | **est** | **a** | **va** |
| nous | **sommes** | **avons** | **allons** |
| vous | **êtes** | **avez** | **allez** |
| ils / elles | **sont** | **ont** | **vont** |

> **être** et **avoir** forment les temps composés (*j'ai parlé, je suis parti* — voir *Le verbe : les temps du passé*). **aller** + infinitif donne le futur proche (*je vais partir* — voir *Le verbe : le futur*).

## Ce que couvre le présent

- le présent proprement dit : *Je travaille en ce moment.*
- une action habituelle : *Je bois du café le matin.*
- une vérité générale : *L'eau bout à 100 degrés.*
- un futur proche avec marque de temps : *Je pars demain.*

Le français n'a pas de forme continue propre : *je travaille* traduit aussi bien *I work* que *I am working*. Pour insister sur le déroulement, on ajoute **être en train de** : *je **suis en train de** travailler*.
