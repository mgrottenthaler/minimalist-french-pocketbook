## Le futur simple

Radical = **infinitif** (les verbes en *‑re* perdent le *‑e* final) + terminaisons **‑ai, ‑as, ‑a, ‑ons, ‑ez, ‑ont** — les mêmes pour tous les verbes, régulières même quand le radical ne l’est pas.

| | parler | finir | vendre |
|---|---|---|---|
| je | parler**ai** | finir**ai** | vendr**ai** |
| tu | parler**as** | finir**as** | vendr**as** |
| il / elle | parler**a** | finir**a** | vendr**a** |
| nous | parler**ons** | finir**ons** | vendr**ons** |
| vous | parler**ez** | finir**ez** | vendr**ez** |
| ils / elles | parler**ont** | finir**ont** | vendr**ont** |

> Les terminaisons sont celles du présent de *avoir* (*ai, as, a, avons, avez, ont*), réduites à *‑ons* et *‑ez* pour *nous* et *vous* — c’est d’ailleurs leur origine historique.

### Radicaux irréguliers fréquents

Le radical change, jamais les terminaisons.

| Infinitif | Radical du futur | Exemple |
|---|---|---|
| être | **ser-** | je serai |
| avoir | **aur-** | j’aurai |
| aller | **ir-** | j’irai |
| faire | **fer-** | je ferai |
| pouvoir | **pourr-** | je pourrai |
| vouloir | **voudr-** | je voudrai |
| voir | **verr-** | je verrai |
| savoir | **saur-** | je saurai |
| venir / tenir | **viendr- / tiendr-** | je viendrai |
| envoyer | **enverr-** | j’enverrai |

## Le futur proche

**aller** au présent + **infinitif** — pour une action prévue, proche ou déjà décidée. Nettement plus fréquent à l’oral que le futur simple pour parler de l’avenir immédiat.

*Je **vais partir**. Il **va pleuvoir**. Nous **allons manger**.*

| Futur simple | Futur proche |
|---|---|
| plan général, prédiction, promesse | intention proche, déjà engagée |
| *Un jour, j’**apprendrai** le russe.* | *Je **vais apprendre** le russe cette année.* |

## Le futur antérieur

**avoir** ou **être** au **futur simple** + participe passé — une action future, achevée avant une autre action future. Obligatoire après **quand, dès que, lorsque, aussitôt que** quand la principale est au futur.

| | |
|---|---|
| j’ | **aurai** parlé |
| je | **serai** parti(e) |

***Quand** tu **auras fini**, appelle-moi.* — pas *quand tu finiras* : l’action de finir doit être achevée avant celle d’appeler.
