## Formation des adverbes en -ment

| Adjectif | Règle | Exemple |
|---|---|---|
| finit par une voyelle au masculin | masculin + **-ment** | vrai → vrai**ment**, poli → poli**ment** |
| finit par une consonne | féminin + **-ment** | lent → lente → lente**ment**, heureux → heureuse → heureuse**ment** |
| **-ant** | → **-amment** | courant → cour**amment** |
| **-ent** | → **-emment** | patient → pati**emment**, évident → évid**emment** |

Les deux terminaisons **-amment** et **-emment** se prononcent de façon identique, malgré l'orthographe différente.

> Exceptions au patron **-ent → -emment** : **lent → lentement**, **présent → présentement** — l'adjectif garde sa forme féminine régulière au lieu de suivre la règle des présents-participes.

### Adverbes irréguliers

| Adjectif | Adverbe |
|---|---|
| bon | **bien** |
| mauvais | **mal** |
| meilleur | **mieux** |
| petit | **peu** |
| gentil | **gentiment** |

## La place de l'adverbe

Aux temps simples, l'adverbe se place normalement **après** le verbe : *Il parle **lentement**.*

Aux temps composés, les adverbes courts et fréquents (**bien, mal, déjà, encore, toujours, souvent, trop, beaucoup**) s'intercalent **entre l'auxiliaire et le participe** ; les adverbes de manière en *-ment* suivent plutôt le participe.

| | |
|---|---|
| adverbe court | J'ai **déjà** mangé. Il a **bien** compris. |
| adverbe en -ment | Il a parlé **lentement**. Elle a répondu **gentiment**. |

## La comparaison

| | |
|---|---|
| supériorité | **plus** vite **que** |
| égalité | **aussi** vite **que** |
| infériorité | **moins** vite **que** |
| superlatif | **le plus** vite, **le moins** vite |

Le superlatif de l'adverbe utilise toujours **le**, invariable — un adverbe n'a ni genre ni nombre.

> Irréguliers : bien → **mieux** → **le mieux** ; peu → **moins** → **le moins** ; beaucoup → **plus** → **le plus**. *mal* a un comparatif littéraire, **pis**, presque disparu sauf dans *tant pis* et *de mal en pis* — à l'oral, on dit *plus mal*.
